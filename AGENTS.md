# Avenra working notes

- At the start of each task, read `../Avenra-memory-book.md` if it exists. It is
  the operator's local Desktop work history; verify current Git/code state before
  relying on older entries.
- At task completion, append the date, request, changes, checks, commit/push
  status, blockers and next steps to that book. Correct superseded information
  explicitly. Keep the book outside Git and deployment bundles.
- Never put credentials, private keys, environment-file contents, personal data
  or raw secret-scanner findings in the book, source, logs or commits.
- Communicate in English. Preserve MFA, CSRF, origin checks, rate limits and TLS
  verification. Admin-wide case visibility and explicitly assigned destructive
  retention are separate policies.
